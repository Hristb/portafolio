**Toda URL es una URI, pero no toda URI es una URL.**

URI (*Uniform Resource Identifier*) identifica un recurso. URL (*Uniform Resource Locator*) además dice cómo llegar a él. `https://hristbartra.dev/about` es una URL (y también URI). `urn:isbn:978-0-13-468599-1` es una URI pero no una URL: nombra el libro, no dice dónde descargarlo.

Lo descubrí leyendo la spec de REST y me costó menos de 5 minutos entenderlo. Nunca más lo voy a confundir.
